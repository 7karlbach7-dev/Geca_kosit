# Zvoz odpadu - Obec Geča (PWA & ICS Export)

Progresívna webová aplikácia (PWA) pre zobrazenie harmonogramu zvozu odpadu v obci **Geča** (spoločnosť KOSIT) s možnosťou exportu do iOS / Google Kalendára.

## Funkcie
- 📱 **PWA (Progressive Web App):** Možnosť pridať na plochu iPhonu aj Androidu ako samostatnú aplikáciu.
- 📅 **Export do Kalendára (.ics):** Jedným kliknutím stiahne/importuje všetky termíny zvozu aj s pripomienkami do systémového kalendára.
- ⚡ **Offline režim:** Vďaka Service Workeru funguje aj bez pripojenia na internet.

## Ako nasadiť na GitHub Pages
1. Nahrajte súbory z tohto ZIP archívu do vášho GitHub repozitára.
2. V nastaveniach repozitára go to **Settings -> Pages**.
3. Zvoľte vetvu `main` (alebo `master`) a kliknite **Save**.
4. Stránku otvorte na telefóne v prehliadači Safari/Chrome.
